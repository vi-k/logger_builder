## Открытые вопросы

1. **Job `oldest-supported` в CI не проверен локально.** Он ставит SDK
   3.6.0, которого на машине нет. Первый прогон CI подтвердит или
   опровергнет. Если упадёт — смотреть на разницу в наборе линтов старого
   анализатора.
2. **`maxBufferSize` и политика сброса не вводились** (см. вердикт по
   M10). Очереди по-прежнему неограниченны, это описано в dartdoc. Форму
   API стоит обсудить отдельно.
3. **Подъём SDK и переход на `lints 6.x`** не делались: при `sdk: ^3.7.0`
   и выше `dart format` переформатирует 38 файлов из 45 (замерено). Нужен
   отдельный коммит «Reformat for the 3.7+ style», иначе диффы утонут.
4. **У волны 0.5.0 нет записи в `docs/records/`.** Что вошло, видно по
   `CHANGELOG.md` и коммитам `313e3f0..89730fb`.
