## Что добавлено

Четыре раздела, оглавление обновлено.

1. **`Why not just if (logging)?`** — после «Performance», как
   продолжение того же аргумента. Суть: `if (logging)` — переключатель
   времени компиляции, логгер — времени выполнения; что даёт второй
   (гранулярность, уровни, сменяемое назначение, настраиваемость для
   пользователей пакета) и почему за это не платят, пока логирование
   выключено. Явно сказано, что одно не заменяет другое.
2. **`Common Scenarios`** — перед «Examples». Четыре рецепта:
   stdout/stderr раздельно, файл через `AsyncPublisherWithBuffer`
   (с `retryBuffer` и обязательным `close()` перед выходом), timestamp,
   раскраска (с оговоркой, что escape-коды не должны попадать в файл,
   и разводом через `MultiPublisher`).
3. **`Common Mistakes`** — шесть ошибок: неленивая интерполяция; лишняя
   ленивость там, где уровень всегда включён; отдача `processLog` вместо
   `log`; `publisher.publish` вместо `publishLog`; `DateTime.now()`
   в форматтере; выход без `flush`/`close`; логирование из трансформера.
4. **`Using logger_builder in your own package`** — логгер отдаётся
   наружу выключенным, пользователь сам ставит `level` и `publisher`,
   иерархия даёт ему настройку по подсистемам, тип `Log` — часть
   публичного API пакета.

Нюанс про лишнюю ленивость (`log.i(() => ...)` бессмысленно, если уровень
включён всегда) владелец дописал в бэклог по ходу работы — попал
в Common Mistakes отдельным пунктом «Deferring what is never deferred».

## Как проверялись примеры

Все фрагменты кода собраны во временные файлы в
`example/logger_builder_examples/bin/_verify/`, прогнаны через
`dart analyze` и запущены. Проверено фактическим исполнением, а не на
глаз:

- публикация в stdout/stderr, в файл (файл действительно создаётся
  и дописывается), раскраска, `MultiPublisher`;
- timestamp: поле `time` в `Log` заполняется временем события;
- **свежий логгер стартует с `Levels.off`** — утверждение из раздела про
  пакеты; логгер без настройки молчит;
- иерархия: `packageLog.level = Levels.error` + `httpLog.level =
  Levels.all` даёт ровно обещанное (видны ошибки пакета и весь http);
- **ошибка с `processLog` реальна и анализатором не ловится**: `@protected`
  не мешает, если уровневый логгер и логгер лежат в одной библиотеке —
  как во всех примерах пакета. Уровень при этом невозможно выключить.

Временные файлы удалены.
